# График работы 2/2

Календарь смен для графика 2/2. Открываешь, выбираешь свою смену и сразу видишь рабочие и выходные дни на любой месяц вперёд.

**Сайт:** https://hodlroad.github.io/work-schedule/

## Что умеет

- Две смены, переключаются одной кнопкой
- Сверху видно, что сейчас (рабочие или выходные) и когда начнутся следующие
- Статистика по месяцу: рабочие и выходные дни и рабочие часы
- Листание месяцев кнопками и свайпом, переход к любой дате
- Тема светлая, тёмная или как в системе
- Работает офлайн и ставится на телефон как приложение (PWA)
- Быстро открывается из кэша, а когда выходит новая версия, показывает плашку с предложением обновиться

## Как устроено

Без сборки и зависимостей. Вся страница лежит в одном `index.html` (HTML, CSS и JavaScript), офлайн-режим даёт service worker в `sw.js`. Сайт раздаёт GitHub Pages прямо из ветки `main`.

Запустить локально:

```bash
python -m http.server 8765
```

После этого открой http://127.0.0.1:8765. Если открыть `index.html` прямо с диска, календарь работает, но офлайн-режим и установка не работают.
